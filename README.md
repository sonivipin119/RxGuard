# 💊 RxGuard | Medical Prescription and Verification System

A secure web application that streamlines **digital medical prescriptions** and ensures their authenticity.  
Built with **Node.js, Express.js, MongoDB**, and **Blockchain integration** to provide tamper-proof, transparent, and trustworthy prescription management for doctors, patients, and pharmacists.  

🚧 **Status:** Currently under active development

---

## Features
- 👨‍⚕️ **Role-based authentication** for Doctors, Patients, and Pharmacists  
- 🔒 **Blockchain-backed verification** to prevent tampering or forgery  
- 📜 Secure **digital prescription upload & storage**  
- 🔍 Instant verification for pharmacies and patients  
- 🛡️ Transparent and trustworthy system for all stakeholders  

---

## 🛠️ Tech Stack
- **Frontend:** React.js
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT / OAuth2  
- **Blockchain:** For immutable storage & verification  

---

## ⚙️ Installation & Setup

1. **Clone the repository**
   ```
   git clone https://github.com/your-username/rxguard.git
   cd rxguard
2. Install dependencies
   ```
   npm install
3. Setup environment variables
   ```
   PORT=5000
   MONGO_URI=your_mongodb_connection
   JWT_SECRET=your_secret_key
   BLOCKCHAIN_NODE_URL=your_blockchain_node
4. Run the application
   ```
   npm start

---

## Usage

- Doctors can create and sign digital prescriptions.
- Patients can access their verified prescriptions securely.
- Pharmacists can verify authenticity before dispensing medicine
